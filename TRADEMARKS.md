## What needs permission

- Publishing an app, on any store or website, named Tide or using the Tide logo or icons.
- Using the brand in a way that suggests your project or product is the official Tide or is endorsed by it.

If you publish a fork, give it a different name and icon. The brand assets are easy to swap: replace the files in `app/assets/brand/` and `app/assets/icons/`, change `name`, `slug` and the bundle identifiers in `app/app.json`, and run `npm run build:icons` from `app/`.
