# Tide Support

Need help with Tide, found a bug, or have an idea? Email
[thisiskurubaran@gmail.com](mailto:thisiskurubaran@gmail.com). In the app,
**Settings > Help & feedback > Report a problem** writes the email for you
and attaches the details that help me fix things.

## Common questions

**Does Tide cost anything?**
No. Every feature and every extension is free, with no subscription.
Extensions are installed from the Extensions screen. There are no
in-app purchases.

**What runs on the device?**
JavaScript (Node.js), Python, Lua, Ruby and PHP run on the device, offline. npm and pip
install pure-JavaScript and pure-Python packages. Anything else, such as
native builds or other languages, needs Remote mode with a Tide server you
host.

**Where are my files?**
In Tide's own storage on the device, included in your device backup. To
work on a folder from Files or iCloud Drive, use New project > Open a
folder; to move a project elsewhere, use Export as .zip.
